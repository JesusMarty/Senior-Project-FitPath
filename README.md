# Senior-Project-FitPath

## Project Overview

FitPath is a personalized fitness and nutriotion planning mobile application degsined to help uses manage their health and welness goals in one place. 

The platform will provide personalized workout and nutrition recommendations based on uses goals, preferences, amd progress. The project will explore features such as workout tracking, nutrion tracking, progress monitoring, amd camera-based functionality. 

This application is being developed as a Senior Project at The University of Texas Rio Grande Valley (UTRGV).
